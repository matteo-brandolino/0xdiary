# 0xdiary

A personal blog documenting a hands-on journey through web security — DVWA, HackTheBox, CTFs, bug bounty concepts, tool exploration.

Posts are technical diaries, not tutorials. The difference: a tutorial tells you the right way to do something; a diary tells you what actually happened, including the detours.

**Live at: [matteo-brandolino.github.io/0xdiary](https://matteo-brandolino.github.io/0xdiary)**

---

Built with [Jekyll](https://jekyllrb.com) and the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme. Hosted on GitHub Pages.
