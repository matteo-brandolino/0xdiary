{% comment %} Site-wide language switcher, rendered as a small badge next to the site title at the top of the sidebar (not a nav-item, not in the bottom social-icon bar — it's a site-language toggle, not a section or a social link, so it gets its own visually distinct spot). On a post page with a translated sibling (page.permalink_lang, populated by jekyll-polyglot when two posts share a page_id), links to that exact translation. On any other page — tabs, the homepage, or a post that has no translation yet — falls back to the current page's own bare URL under the target language's prefix. That fallback is safe because page.url is always the bare, language-prefix-free permalink (Polyglot only adds the /it/ prefix via the destination folder and a later regex pass over rendered links, never by rewriting page.url itself) — so toggling the prefix lands on the correct page for tabs/home, and on the graceful English-fallback Polyglot already serves for an untranslated post under /it/. page.page_id is required before trusting permalink_lang: when a page has no explicit page_id front matter (all four tabs), Polyglot still auto-derives one from the page's own URL and self-pairs it under the default_lang key — but the value it stores there is the RAW, unresolved front-matter permalink (tabs never get theirs resolved the way posts do, since that only happens for documents with an explicit lang set), i.e. the literal string "/:title/". Gating on page.page_id (only ever set by us, on real translated pairs) skips that broken implicit pairing entirely. Styled with an inline style rather than a class: Chirpy's production CSS is a slim custom Sass bundle, not full Bootstrap, so a class like "badge" isn't guaranteed to actually be styled. Inline keeps this independent of that. Positioned absolutely (relative to the inline-block wrapper around just the title, in sidebar.html) rather than sitting inline in a flex row: an inline badge widened the whole title+badge cluster and threw off the title's own centering. Absolute positioning removes it from that flow entirely, so the title stays exactly where it always was. The visible flag shows the CURRENT language (site.active_lang), not the destination — a persistent "you are here" indicator you click to toggle, not an announcement of what you'll get. The href still points at the other language's page either way. Vertically centered on the title's own line (top: 50% + translateY(-50%) relative to the inline-block wrapper, whose height equals the title's line height) rather than pinned to its top, so it reads as sitting beside the text, not above it. {% endcomment %} {% for target_lang in site.languages %} {% if target_lang != site.active_lang %} {% assign target_prefix = "" %} {% unless target_lang == site.default_lang %} {% assign target_prefix = "/" | append: target_lang %} {% endunless %} {% if page.page_id and page.permalink_lang[target_lang] %} {% assign switch_path = page.permalink_lang[target_lang] %} {% else %} {% assign switch_path = page.url %} {% endif %} {% capture switch_href %}{{ site.baseurl }}{{ target_prefix }}{{ switch_path }}{% endcapture %} {% capture switch_aria %}{% if target_lang == "it" %}Passa all'italiano{% else %}Switch to English{% endif %}{% endcapture %} {% if site.active_lang == "it" %}🇮🇹{% else %}🇬🇧{% endif %} {% endif %} {% endfor %}
